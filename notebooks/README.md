# Notebooks

Exploration, training, and evaluation notebooks for the face detection and emotion classification models.

| Notebook | Purpose |
|---|---|
| `image_preprocessing.ipynb` | Image-level preprocessing experiments |
| `pj3_1_yolo_training.ipynb` | YOLO face detector training |
| `pj3_2_face_data_added.ipynb` | Dataset augmentation / additions |
| `pj3_3_cls_train.ipynb` | Emotion classifier training |
| `pj3_4_eval.ipynb` | Final evaluation |
| `vit_classifier.ipynb` | ViT-based classifier experiment |
| `vit_detector.ipynb` | ViT-based detector experiment |

Final weights are written to `../models/` (gitignored).
